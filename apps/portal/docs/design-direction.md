# Portal (`/`) デザイン方針

`/` は、制作物をまとめた1ページの LP。実体は `components/portal-landing.tsx` と
`app/globals.css`。

見た目の正本は `portfolio/webSites/sites/08-portal-axis/`。あちらで 06(足し算)・
07(粒子)・08(座標系)の3本を試作して比べ、08 を採用した。ここはその移植で、
**セレクタ名・文言・数値をあちらと同じに保っている。**

## 役割

- ウェブ上で利用できるアプリと、ポートフォリオ用に制作したサイトを一覧にする。
- 各制作物へ直接移動できる一次導線を提供する。
- 制作の手順(Method)と連絡先(Contact)を同じページに置く。
- アプリ固有の状態や設定をポータルへ持ち込まない。

## 規律

[Antigravity](https://antigravity.google/) を計測して分かった規律を、そのまま制約として持ち込む。
06(足し算)との違いは、足す量ではなく置き場所である。

1. 派手さは演出層(座標系と重力場)に隔離する。
2. CSS の `@keyframes` は出現とカーソル点滅の2つだけ。例外は JS が止まったときの保険(`axis-fallback`・`loader-giveup`)で、どちらも 0 秒で切り替わるだけの物。
3. `transition` は 0.12〜0.4秒。対象は `opacity` / `transform` / `color` / `background` のみ。
4. 色は「素の階調 → 役割名」の2層。有彩色は1色だけ。部品は `--grey-*` を直接見ず、役割名だけを見る。
5. 暗転は1回だけ。最後に置く。
6. 大きい字は字間を締め、小さい字は開く。

## 情報設計

- ヒーローは直交座標と積分領域を静かな数学的モチーフとして使い、主文言は
  「常に、学びを止めない」とする。曲線・短冊・点はどれも「積み上がる」ことを言っていて、
  制作物が増えることと重ねている。
- Works は3タブ。ピックアップ5件を先に置き、残りをアプリ・サイトのタブに分ける。
  ピックアップは画像が主役。同じ作品の別カットを3枚重ね、本文の幅いっぱい(64rem まで)に置き、文はその下に2列で組む。
  重ねはスクロールで斜めから正面へ起きる(ヒーローの 3D が正面から斜めへ起きるのと逆向きの同じ動き。2026-11-23 本人「画像が小さくインパクトがない」)。
  重ねをずらす向き(`--dir`)と傾く向きは1件ごとに入れ替える。
- Method は6つの工程(分解・設計・組立・検査・納品・改善)を一周する斜めの図(静止。`components/method-flow.tsx`)とカード6枚。動画とWebの実例を各カードに添える(本人 2026-11-25)。暗転の帯を1回だけ挟んでから、明るい面に戻して Contact を置く。
- フッターの巨大ワードマークは、1729 の各字をばらばらに持ち上げて名前の由来を字の位置で言う。
- 架空サイトを含むので、フッターに架空である旨を明記する。

## 技術境界

- `PortalLanding` は server component のまま保つ。状態を持つのはタブの選択(`works-tabs.tsx`)と
  重ねの順番(`pick-stack.tsx`)だけで、どちらもその部品の中に閉じている。
- 演出層は文書の下に敷き、当たり判定を持たせない。文書側の部品は動かさない。
- **JS が無い・動きを減らす設定でも、図と文字が完成形で出る。**
  `axis-figure.tsx` は GSAP を読めなくても `settle()` で完成形を描き、2.5秒の保険タイマーを持つ。
  `gravity-field.tsx` は最初の1枚を必ず描き、画面外では `requestAnimationFrame` を止める。
  重ねの3枚は「開いた形」が初期値で、押せる見た目は JS が動いてから付ける。
- タブ切り替えは動きではなく機能なので、`prefers-reduced-motion` でも必ず働く。
- クロスアプリ遷移と `public/sites/` へのリンクは、素の `<a>` と `NEXT_PUBLIC_BASE_PATH` prefix で組む。
- LP の見た目は `app/globals.css` に閉じ、共有トークン・各アプリを変更しない。
- GitHub Pages の静的 export と trailing slash を維持する。

## ヒーローの 3D(2026-11-23、本人の注文。2026-11-26 に Hero から一旦外した)

注文: 座標系と積分の演出案は残し、(1) 2D から 3D に (2) 面積の短冊それぞれに映像を映す (3) 3D を読むので最初に読み込み画面を出す。

### 背景(2026-11-23 本人が 4 案から「光の粒が漂う奥行き」に決めた)

`lib/hero-backdrop.ts`。暗い地に粒がゆっくり上へ流れ、1 割の粒はオレンジ。地は上端をヘッダー(黒)より明るい灰青にし、下へ濃紺に沈める(本人「暗すぎてヘッダーとの境目が分からない」)。明るさは 3 段から最も暗い 1 段目に決めた(本人 2026-11-23)。読み込み画面とヒーローの CSS の地は `--hero-deep`(下端の色)。2D のボタンと音のボタンは暗い地で読める色にする。2D に戻ったときは白の地のまま。

字: オレンジと黒は**字の色**のこと。配分は 3D にする前の HTML のまま(見出し・ロゴ行・印は無彩色、小見出しは一段暗い無彩色、ロゴの数字 1729 だけオレンジ)。暗い地なので暗い地の側の色(--inverse-on-surface・--accent-on-inverse)を明るい鋼にし、弱く自ら光らせる。縁・側面・影にオレンジを使わず、色の無い鋼の光の向きに沿った明暗で厚みを見せる(本人 2026-11-23 の訂正)。線路(レール)はオレンジのまま、上を走る球は外した。

### 鋼と 3D の字(2026-11-23、本人の直し「3D の動きは良いが、まだ」)

- 質感は磨いた鋼。色はサイトの配色(オレンジと黒)に戻した(本人 2026-11-23 の 2 回目の直し)。軸・枕木・ラベル・字の面は黒の鋼、レール・点・字の縁はオレンジの鋼、ロゴの数字は面もオレンジ。短冊の側面と上面は左(古い)の黒から濃いオレンジを経て右(新しい)のオレンジへ 1 本ずつ濃さを変える。色は CSS の変数(--grey-1100・--red-600・--red-500)から読む。映像の面は映像のまま、短冊の側面と上面・軸・矢じり・曲線・点・ラベルを鋼にする。金属は映り込みで金属に見えるので、`RoomEnvironment` を環境マップにして、そのまわりをゆっくり回して光を流す
- ヒーローの 3 行(ロゴ行・見出し・小見出し)も同じ鋼の 3D の字にする。ボタンは 2D のまま。背景は上の節
- 軸は太い鋼のパイプ(半径 5)と大きめの円錐の矢じり、原点は球で丸める。曲線は短冊の奥行きいっぱいに敷いた線路にする(2 本のレールを短冊の手前と奥の縁に、枕木を弧長 24 ごと)。点は 2 本のレールの間を走る(本人 2026-11-23「細い線のまま」「線路のような立体に」)
- 読みやすさ: 字の面は暗めの鋼、面取りと側面を明るい鋼にする。字の層の傾きは数度まで
- 字の位置は HTML の字が組まれた位置を1字ずつ測って置く(数値を持たない)。HTML の字は消さず透明にするので、読み上げ・選択・折り返しは HTML のまま。3D を試す間はヒーローの見出しを打たずに待ち、3D が出たら字の出現は 3D が受け持つ
- 字形は `public/hero/hero-text.json`(three の typeface、出る字だけ約 23KB)。文言を変えたら `python apps/portal/scripts/build-hero-font.py` を打ち直す。足りない字がある行は 2D の字のまま残る。字形の読み込みに失敗したら全体を 2D に戻す

## 申し送り

移植では 08 の見た目に合わせることを優先し、次は直していない。

- ~~**書体。**~~ 解消済み。`--face` は `"Noto Serif JP", serif` だったが、フォントを
  1本も読み込んでいなかったため、第1候補は常に外れて総称 `serif` に落ちていた
  （Windows は游明朝、macOS はヒラギノ明朝 ProN、Linux は中国語のゴシック
  WenQuanYi Zen Hei。Chromium の `CSS.getPlatformFontsForNode` で実測）。
  Noto Sans JP を `next/font/google` で読み込み、`--face` をそこへ向けた。
  next/font はビルド時に self-host するので、静的 export でも実行時の外部アクセスは無い。
  **08 側（`portfolio/webSites/sites/08-portal-axis/`）は未対応。** 別リポジトリにあるため
  ここでは直せていない。`assets/css/fonts.css` の `@font-face` を Noto Sans JP に揃え、
  `style.css` の `--face` を同じ形にすること。
- **画像の取りこぼし。** `lib/works.ts` が bucket に無い画像名を書いても、いまは誰も止めない。
  team-t は `npm run validate` でそれを見ている(`scripts/validate-team-t-app.mjs`)。
  同じものを portal にも置くと、この穴が塞がる。
- **視差。** 08 は `main.js` と `axis.js` が同じ `.hero__stage` に別々の視差を掛けていて、
  後から読まれる `axis.js` の 10% が実際の見た目だった。ここは1つに寄せている。
