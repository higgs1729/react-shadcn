# Portal (`/`) デザイン方針

`/` は、制作物をまとめた1ページの LP。実体は `components/portal-landing.tsx` と
`app/globals.css`。

見た目の正本は `portfolio/webSites/sites/08-portal-axis/`。あちらで 06(足し算)・
07(粒子)・08(座標系)の3本を試作して比べ、08 を採用した。ここはその移植で、
**セレクタ名・文言・数値をあちらと同じに保っている。**

## 役割

- ウェブ上で利用できるアプリと、ポートフォリオ用に制作したサイトを一覧にする。
- 各制作物へ直接移動できる一次導線を提供する。
- 制作の手順(Method)と連絡先(Contact)を同じページに置く。
- アプリ固有の状態や設定をポータルへ持ち込まない。

## 規律

[Antigravity](https://antigravity.google/) を計測して分かった規律を、そのまま制約として持ち込む。
06(足し算)との違いは、足す量ではなく置き場所である。

1. 派手さは演出層(座標系と重力場)に隔離する。
2. CSS の `@keyframes` は出現とカーソル点滅の2つだけ。
3. `transition` は 0.12〜0.4秒。対象は `opacity` / `transform` / `color` / `background` のみ。
4. 色は「素の階調 → 役割名」の2層。有彩色は1色だけ。部品は `--grey-*` を直接見ず、役割名だけを見る。
5. 暗転は1回だけ。最後に置く。
6. 大きい字は字間を締め、小さい字は開く。

## 情報設計

- ヒーローは直交座標と積分領域を静かな数学的モチーフとして使い、主文言は
  「常に、学びを止めない」とする。曲線・短冊・点はどれも「積み上がる」ことを言っていて、
  制作物が増えることと重ねている。
- Works は3タブ。ピックアップ3件を先に置き、残りをアプリ・サイトのタブに分ける。
  ピックアップは左右を交互に入れ替え、画像は同じ作品の別カットを3枚重ねる。
- Method は4段。暗転の帯を1回だけ挟んでから、明るい面に戻して Contact を置く。
- フッターの巨大ワードマークは、1729 の各字をばらばらに持ち上げて名前の由来を字の位置で言う。
- 架空サイトを含むので、フッターに架空である旨を明記する。

## 技術境界

- `PortalLanding` は server component のまま保つ。状態を持つのはタブの選択(`works-tabs.tsx`)と
  重ねの順番(`pick-stack.tsx`)だけで、どちらもその部品の中に閉じている。
- 演出層は文書の下に敷き、当たり判定を持たせない。文書側の部品は動かさない。
- **JS が無い・動きを減らす設定でも、図と文字が完成形で出る。**
  `axis-figure.tsx` は GSAP を読めなくても `settle()` で完成形を描き、2.5秒の保険タイマーを持つ。
  `gravity-field.tsx` は最初の1枚を必ず描き、画面外では `requestAnimationFrame` を止める。
  重ねの3枚は「開いた形」が初期値で、押せる見た目は JS が動いてから付ける。
- タブ切り替えは動きではなく機能なので、`prefers-reduced-motion` でも必ず働く。
- クロスアプリ遷移と `public/sites/` へのリンクは、素の `<a>` と `NEXT_PUBLIC_BASE_PATH` prefix で組む。
- LP の見た目は `app/globals.css` に閉じ、共有トークン・各アプリを変更しない。
- GitHub Pages の静的 export と trailing slash を維持する。

## 申し送り

移植では 08 の見た目に合わせることを優先し、次は直していない。

- **書体。** 08 は `--face` が `"Noto Serif JP", serif` なのに、同梱の subset は
  Noto Sans JP のままで、実際には汎用 serif で描かれていた。ここも同じ状態に合わせて、
  フォントを読み込んでいない。直すなら Noto Serif JP の subset を作って自己ホストし、
  08 と同時に直す。
- **画像の取りこぼし。** `lib/works.ts` が bucket に無い画像名を書いても、いまは誰も止めない。
  team-t は `npm run validate` でそれを見ている(`scripts/validate-team-t-app.mjs`)。
  同じものを portal にも置くと、この穴が塞がる。
- **視差。** 08 は `main.js` と `axis.js` が同じ `.hero__stage` に別々の視差を掛けていて、
  後から読まれる `axis.js` の 10% が実際の見た目だった。ここは1つに寄せている。
